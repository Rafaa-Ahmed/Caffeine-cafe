# CAFFEINE CAFE WEBSITE

## PROJECT OVERVIEW
Caffeine Cafe is a multi-page website designed to showcase a cafe's menu, introduce the business, and provide basic customer interactions.

## Live Website
[Visit Caffeine Cafe](https://rafaa-ahmed.github.io/Caffeine-cafe/)

## PROJECT FILES
- index.html  : Home page featuring the cafe's introduction and highlights.
- menu.html   : Menu featuring coffee, tea, desserts, product filters, and a demo shopping cart.
- info.html   : About section, sample sales and ratings, contact form, policies, and demo login/sign-up forms.
- style.css   : Custom styling, colors, layouts, and responsive design.
- script.js   : JavaScript interactions for product filtering, cart functionality, and demo forms.

## View the Website Locally
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your web browser.
4. Navigate through the website using the navigation menu.

## TECHNOLOGIES USED
- HTML5: Structures the website content.
- CSS3: Styles the pages and controls the visual appearance.
- Bootstrap 5: Provides responsive layouts and reusable components.
- JavaScript: Handles interactive features.

## IMPORTANT NOTES
- Bootstrap is loaded through a CDN link in each HTML page. An internet connection is required to load Bootstrap's external resources.
- The shopping cart, contact form, login, and sign-up features are demonstrations only.
- No backend, database, real payment processing, or actual user authentication is connected.
- Sales figures and ratings are sample data used for display purposes.
